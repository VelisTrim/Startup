# 🎯 Foxstep - приложение для борьбы с прокрастинацией
> **Слоган:** *Мы помогаем фокусироваться, контролировать и действовать!*

Для людей, имеющих большое количество задач ежедневно, мы создаём приложение для продуктивного управления своим временем, которое помогает бороться с прокрастинацией и выполнять поставленные цели. 
Мы собрали самые эффективные методы для фокусировки на целях и задачах.
